# AR-рой на Windows

## Подготовка и запуск

1. Распакуйте архив в доступную для записи папку. Подключите камеры и проектор к этому компьютеру. Для проектора используйте режим Windows **Расширить эти экраны**.
2. Выполните `setup.cmd`. Для **Python 3.10 x64** зависимости входят в `wheelhouse/` и устанавливаются в `.venv` локально. Для другой совместимой версии Python установщик получит зависимости через pip.
3. Выполните `start.cmd`. Он запускает глубину, нативный вывод, ArUco и сайт. Откройте [поле роя](http://127.0.0.1:8765/swarm/?live=1) и проверьте статус обеих камер.
4. В **Настройках проектора** выберите дисплей, разрешение и полный экран. Проверьте совмещение по известным точкам рабочей области. Для проверки ArUco положите метку `DICT_4X4_50` с ID 0–5 и стороной 50 мм в обзор обеих камер.

Комплектная калибровка ожидает левый индекс `1` и правый `0`. После изменения оптики или положения камер проверьте геометрию перед точной проекцией. [Порядок калибровки](../README.md#калибровка-после-монтажа).

```powershell
.\start.cmd --display 2 --projector-resolution 1280x800
```

Режимы берутся из возможностей подключённого дисплея. Для полного экрана нужны пропорции калибровочного растра, здесь 16:10. Если активный режим не подходит, приложение открывает диагностическое окно. Windows проверяет выбранный режим перед переключением и при штатном выходе восстанавливает предыдущий. Для физического совмещения настройки масштабирования и оптики проектора должны совпадать с установками калибровки. [Проверка и смена режима Windows](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-changedisplaysettingsexw).

Для отладки есть `start.cmd --windowed`. `start-swarm.cmd` запускает только ArUco и сайт. Остановите один экземпляр перед запуском другого.

## Настройки

| Настройка | Действие |
| --- | --- |
| Дисплей, разрешение, полный экран | Выбирают нативный вывод из режимов Windows, совместимых с калибровкой |
| Оформление | `raw` без сглаживания, `balanced` умеренное, `smooth` более выраженное |
| Заполнение | `conservative` ограничивает восстановление пропусков, `surface` использует плотное восстановление |
| Шумоподавление пола | 15 мм. Параметр запуска `--height-noise-mm` |
| Следы | «Шлейф частиц» управляет траекториями отдельно от карты. В режиме камер траектория строится по измеренным положениям |

`--width` и `--height` задают размер калибровочного растра. `--projector-resolution` задаёт размер физического вывода. Выбор режима дисплея сохраняет калибровочные файлы.

Служба открывает по одному потоку на камеру. Для ArUco она берёт свежую пару полных кадров раз в секунду. Глубина продолжает обрабатываться в 640×360 или 1280×720. При запуске проверяются объявленные обеими камерами более крупные режимы с пропорциями и известной областью съёмки калибровки. Если обе камеры одновременно не выдали кадры более крупного режима, используется 1280×720 и сообщается причина. После подключения новых устройств перезапустите захват для повторной проверки максимального режима. [Режимы захвата DirectShow](https://learn.microsoft.com/en-us/windows/win32/directshow/configure-the-video-output-format).

## Горячие клавиши

| Клавиша | Действие в нативном окне |
| --- | --- |
| **S** | `raw` → `balanced` → `smooth` |
| **F** | `conservative` ↔ `surface` |
| **1 / 2** | Расчёт глубины в 640×360 / 1280×720 |
| **B / G** | Стереопоиск BM / SGBM |
| **R** | Принудительное обновление карты |
| **P** | Калибровка рабочей области |
| **V** | Проверка расстояния при запуске с `--reference-m` |
| **Esc / Q** | Остановка и освобождение устройств |

В браузерном демо стрелки двигают выбранный маркер, **Q / E** поворачивают его. **Esc** закрывает полноэкранный вывод эффектов браузера.

## Порты

| Порт | Назначение |
| --- | --- |
| **8765 TCP** | Статическая страница, HTTP API, растровые снимки. Параметр `--lan-preview-port` |
| **8766 TCP** | `/ws/depth` для уведомлений о снимке и `/ws/markers` для ArUco. Параметр `--stream-port` |
| **8080 TCP** | Необязательный локальный сервер для симуляции из `web/dist/` |

Менять настройки физического проектора можно со страницы службы AR. Внешнему статическому хосту можно разрешить чтение через `--lan-preview-origin`, если браузер допускает доступ к локальной службе. При недоступном WebSocket сайт использует HTTP. [Контракт API](GUI_API.md).
