# AR-рой в браузере

## Статический хостинг

Загрузите **содержимое** [dist/](dist/) в нужный каталог хостинга. Входная страница — `index.html`. Все ссылки на ресурсы относительные. Для модулей `.mjs` хостинг должен отдавать тип `text/javascript` или `application/javascript`. Сборка запускается без установки Node.js и внешних библиотек.

Для локального просмотра из корня репозитория:

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory web/dist
```

Откройте [симуляцию](http://127.0.0.1:8080/). Перетащите маркер мышью или касанием. В фокусе поля стрелки перемещают выбранный маркер, а **Q** и **E** поворачивают его. Кнопка сброса возвращает автоматическое движение.

## Камеры и проектор

```powershell
.\start.cmd --aruco --windowed --x 0 --y 0
```

Стереотрекинг использует метки ArUco `DICT_4X4_50` с ID 0–5. Сторону 50 мм можно изменить через `--aruco-marker-mm`. Печатная верхняя грань метки задаёт направление стрелки. Нужны сохранённая калибровка стереопары и 3D-модель проектора.

1. Откройте [AR-рой](http://localhost:8765/swarm/) на компьютере с камерами или по его LAN-адресу. Выберите **Камеры → Подключить**. Адрес службы заполнится автоматически.
2. Переместите окно браузера на экран проектора и нажмите **На проектор**. Для совпадения с калибровкой используйте разрешение проектора, указанное при калибровке. Для выхода нажмите **Esc** или коснитесь поля и выберите **Выйти из проекции**.

Для подключения из приложения на другом хосте передайте его origin при запуске, например `--lan-preview-origin https://ar.example.com`. В интерфейсе укажите адрес службы AR, доступный браузеру. Если браузер блокирует доступ к локальной службе с внешнего сайта, откройте страницу `/swarm/` по адресу самой службы.

`GET /api/v1/markers` возвращает `frame_id`, возраст кадра `age_s`, размеры и границы проекции и массив `markers` с полями `id`, `x`, `y`, `angle`. Координаты заданы в пикселях полного изображения проектора от верхнего левого угла, угол — в радианах по часовой стрелке от оси X. Позы обновляются до 15 раз в секунду, Canvas анимирует эффекты между отсчётами.
