# AR-рой в браузере

## Статический хостинг

Загрузите **содержимое** [dist/](dist/) в нужный каталог хостинга. Входная страница — `index.html`. Все ссылки на ресурсы относительные. Для модулей `.mjs` хостинг должен отдавать тип `text/javascript` или `application/javascript`. Сборка запускается без установки Node.js и внешних библиотек.

Для локального просмотра из корня репозитория:

```powershell
python -m http.server 8080 --bind 127.0.0.1 --directory web/dist
```

Откройте [симуляцию](http://127.0.0.1:8080/). Перетащите маркер мышью или касанием. В фокусе поля стрелки перемещают выбранный маркер, а **Q** и **E** поворачивают его. Кнопка сброса возвращает автоматическое движение.

## Камеры и проектор

Подключите обе камеры к компьютеру с Python и запустите из корня проекта:

```powershell
.\start.cmd
```

Откройте [поле роя с камерой](http://127.0.0.1:8765/swarm/?live=1). При запуске с другого устройства замените `127.0.0.1` на IP компьютера с камерами. Остановить службу можно сочетанием **Ctrl+C** в её консоли.

В браузере статус каждой камеры показывает её индекс и частоту кадров. В комплектной калибровке левая камера имеет индекс `1`, правая — `0`. Если камера без сигнала, проверьте подключение и закройте программы, которые используют эту камеру, включая предыдущий запуск `start.cmd`. Служба повторяет подключение автоматически. При перестановке камер или смене оптики проверьте соответствие [калибровке](../project/README.md#калибровка-после-монтажа).

Стереотрекинг использует метки ArUco `DICT_4X4_50` с ID 0–5. Сторону 50 мм можно изменить через `--aruco-marker-mm`. Верхняя грань метки задаёт направление стрелки. Для появления метки на поле её должны видеть обе камеры. Масштаб и положение задаются сохранённой стереокалибровкой и 3D-моделью проектора.

Для вывода карты на физический дисплей выберите дисплей, совместимое разрешение и полный экран в **Настройках проектора**. Веб-слой глубины и карта проектора обновляются из одного снимка. Кнопка **На проектор** выводит световые эффекты браузера. `start-swarm.cmd` запускает только трекинг меток.

Для подключения из приложения на другом хосте передайте его origin при запуске, например `--lan-preview-origin https://ar.example.com`. В интерфейсе укажите адрес службы AR, доступный браузеру. Если браузер блокирует доступ к локальной службе с внешнего сайта, откройте страницу `/swarm/` по адресу самой службы.

Позы ArUco обновляются раз в секунду. Потерянная метка кратко показывается пунктиром в последней известной позиции, с временем последнего обнаружения. Её след постепенно затухает. [HTTP API и WebSocket](../project/docs/GUI_API.md).
