# AR-подсветка поверхности

Две камеры измеряют высоту над полом, проектор подсвечивает рельеф. Рабочий диапазон — **0–50 см**. Поверхности выше 50 см отображаются чёрным.

Сейчас готовится окончательное крепление. После монтажа нужно заново проверить стереокалибровку, снять пустой пол и откалибровать проектор в 3D. Точное попадание проекции на выступы пока не проверено.

Запуск после настройки — **[start.cmd](start.cmd)**. Остановка — **Esc**. В режиме обновления по изменениям неподвижная сцена удерживается, а при движении публикуются новые снимки.

Калибровочные данные находятся в `project/stereo_calibration/`.

## AR-рой в браузере

В [web/dist/](web/dist/) лежит статическая сборка. В режиме камер сайт показывает полупрозрачный слой глубины, координаты меток ArUco и их траектории. Полноцветная карта выводится на проектор нативным окном. Оба представления строятся из одного снимка поверхности в координатах сохранённой калибровки.

Запустите на компьютере с камерами и проектором. `setup.cmd` выполняется при первой установке:

```powershell
.\setup.cmd
.\start.cmd
```

Откройте [поле роя с камерой](http://127.0.0.1:8765/swarm/?live=1). Браузер покажет состояние камер и настройки проектора. [Инструкция Windows и состав выпуска](project/docs/WINDOWS_RELEASE.md) · [Проверка по 12 пунктам](project/docs/VERIFICATION.md).
