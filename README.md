# AR-подсветка поверхности

Две камеры измеряют высоту над полом, проектор подсвечивает рельеф. Рабочий диапазон — **0–50 см**. Поверхности выше 50 см отображаются чёрным.

Сейчас готовится окончательное крепление. После монтажа нужно заново проверить стереокалибровку, снять пустой пол и откалибровать проектор в 3D. Точное попадание проекции на выступы пока не проверено.

Запуск после настройки — **[start.cmd](start.cmd)**. Остановка — **Esc**. Пока сцена статична, изображение удерживается; при движении обновляется примерно раз в секунду.

Калибровочные данные находятся в `project/stereo_calibration/`.

## AR-рой в браузере

В [web/dist/](web/dist/) лежит готовая статическая сборка. Симуляция показывает шесть маркеров, их курс, световые кольца при повороте и шлейф частиц при движении. Кнопка «На проектор» выводит эффекты на чёрном фоне в координатах поля.

Запуск на компьютере с камерами и проектором:

```powershell
.\start.cmd --aruco --windowed --x 0 --y 0
```

Откройте [поле роя](http://localhost:8765/swarm/), выберите «Камеры» и нажмите «Подключить». [Локальная симуляция и размещение на хостинге](web/README.md).
